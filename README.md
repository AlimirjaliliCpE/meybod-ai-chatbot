# 🤖 چت‌بات هوش مصنوعی دانشگاه میبد

**سامانه پاسخ‌گویی هوشمند دانشگاه میبد**

این پروژه با هدف ایجاد بستری هوشمند، سریع و در دسترس برای پاسخ‌گویی به پرسش‌های دانشجویان دانشگاه میبد توسعه یافته است. این سامانه با بهره‌گیری از مدل زبانی محلی و بدون وابستگی به APIهای پولی، امکان تعامل کاربران با هوش مصنوعی را فراهم می‌کند.

## ✨ امکانات

- پاسخ‌گویی هوشمند به پرسش‌های کاربران به زبان فارسی
- استفاده از مدل زبانی محلی Qwen 2.5 3B
- امکان افزودن اطلاعات و مستندات رسمی دانشگاه
- محدودیت درخواست‌ها برای جلوگیری از استفاده بیش از حد
- عدم نیاز به API پولی
- طراحی رابط کاربری ساده و قابل توسعه
- قابلیت توسعه برای اتصال به منابع اطلاعاتی دانشگاه

## 🛠️ فناوری‌های استفاده‌شده

- Python
- Flask
- Ollama
- Qwen 2.5 3B
- HTML
- CSS
- JavaScript
- Flask-Limiter

## 🔐 حریم خصوصی و پردازش اطلاعات

در معماری فعلی، پردازش پیام‌ها توسط مدل زبانی محلی انجام می‌شود و سامانه برای تولید پاسخ به APIهای خارجی هوش مصنوعی متکی نیست.

در نسخه اولیه، ذخیره‌سازی دائمی متن مکالمات کاربران در پایگاه داده در نظر گرفته نشده است. تاریخچه مکالمه در سمت مرورگر صرفاً برای حفظ پیوستگی پاسخ‌ها در طول تعامل نگهداری می‌شود.

راه‌اندازی نهایی سامانه روی زیرساخت دانشگاه، مستلزم بررسی تنظیمات امنیتی، دسترسی‌ها، زیرساخت میزبانی و سیاست‌های حفظ اطلاعات توسط واحد فناوری اطلاعات دانشگاه است.
